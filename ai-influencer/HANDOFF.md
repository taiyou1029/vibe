# 引き継ぎメモ：画像生成からの続き

このメモは、クラウドのClaude Codeセッションで作ったAIインフルエンサーのキットを、先生のPCのClaude Codeセッションで続けるためのものです。クラウド側にはGPUがなく、画像生成サービスにも接続できなかったため、画像生成から先をPC側に任せます。

## 最初にやること

```bash
# まだクローンしていない場合
git clone https://github.com/taiyou1029/vibe.git
cd vibe
git checkout ccr-854438e4-rmob8v

# すでにクローンしている場合
git fetch origin ccr-854438e4-rmob8v
git checkout ccr-854438e4-rmob8v
git pull origin ccr-854438e4-rmob8v
```

そのあと、次の順に読んでください。

1. `ai-influencer/README.md`：全体像、費用、守るべきルール
2. `ai-influencer/01-characters.md`：3人のキャラ設定（見た目の固定する特徴を含む）
3. `ai-influencer/02-higgsfield-prompts.md`：画像・動画のプロンプト（Higgsfield向けに書いたものですが、英語のプロンプトはほかのツールでもそのまま使えます）
4. `ai-influencer/04-posts.md`：投稿ごとに使う画像のID（A-1、B-3 など）

## ここまでに決まっていること

- 日本向けで、キャラは3人：ミオ（美容）、ソウタ（宅トレ）、ユイ（家計）
- 3人とも「AIで生成したバーチャルキャラクター」だとプロフィールで明示し、投稿時はInstagramのAIラベルをオンにする
- 体験談や効果の断定は書かない（景品表示法・薬機法などのため）
- ワークブック3冊のPDFとプレビュー画像は完成済み（`ai-influencer/workbooks/dist/`）
- 副業の調査（`reports/日本の副業 根拠のある稼ぎ方.md`）の結論として、このテストは「損失の上限を決めた実験」として扱う。撤退基準は「Day 7までに損益分岐の冊数に届かなければやめる」

## PC側でやってほしいこと

### 1. 画像を生成する

PCで使える画像生成ツールを使い、`02-higgsfield-prompts.md` の次の画像を作ってください。

| キャラ | 基準画像 | シーン画像 |
|---|---|---|
| ミオ | A-0 | A-1〜A-6 |
| ソウタ | B-0 | B-1〜B-6 |
| ユイ | C-0 | C-1〜C-6 |

- まず基準画像（A-0 / B-0 / C-0）を各4〜8枚作り、先生に1枚選んでもらう
- シーン画像では、選んだ基準画像を参照画像として使い、顔をそろえる。ツールに参照画像やキャラ固定の機能がなければ、基準画像のプロンプトの人物説明をそのまま毎回入れる
- サイズは縦長：フィード用は4:5（例：1080×1350）
- 画像に文字を入れない（日本語の文字は崩れやすいため、文字はあとで乗せる）

### 2. 生成した画像を確認する

- 指・手の形がおかしくないか
- 背景に崩れた文字やブランドロゴが写り込んでいないか
- 実在の人物や既存のAIインフルエンサーに似すぎていないか
- 3人の見た目が、`01-characters.md` の「固定する特徴」（髪型・ほくろ・メガネ・服など）と合っているか
- ソウタのB-2（スクワット）は、ひざとつま先の向き、背中のラインが自然か。不自然なら使わない

### 3. 保存してプッシュする

次の場所に保存してください。ファイル名はプロンプトのIDに合わせます。

```
ai-influencer/assets/mio/A-0.png  … A-6.png
ai-influencer/assets/souta/B-0.png … B-6.png
ai-influencer/assets/yui/C-0.png  … C-6.png
```

保存したら、同じブランチ `ccr-854438e4-rmob8v` にコミットしてプッシュします。

### 4. 動画を作れない場合

PCのツールで動画（話す動画を含む）が作れない場合は、`04-posts.md` のリールを「静止画をつないだ映像＋テロップ＋BGM」に置き換えてください。台本の文はそのままテロップに使えます。

## 費用の見直し

画像をPCで無料で作れるなら、Higgsfieldの月額（約15,000円）が不要になり、損益分岐の冊数が大きく下がります。その場合は `ai-influencer/README.md` と `ai-influencer/05-listing.md` の費用と損益分岐の表を、実際にかかる費用で更新してください。
