# AIインフルエンサー × デジタル商品 7日間テスト

Mark Tilbury の動画「[I Tried The LAZIEST Way to Make Money With AI](https://youtu.be/LlhTEttKcwQ)」と同じ流れを、日本向けに組み直した実行キットです。

## 元の動画でやっていたこと

1. Claude でAIインフルエンサーのキャラクターを3人つくる
2. Higgsfield でそのキャラの写真と話す動画をつくる（月$99のプラン）
3. Instagramに3アカウントをつくって投稿し、反応を比べる
4. いちばん伸びたキャラで、$12のワークブック（PDF）を売る

| 項目 | 金額 |
|---|---|
| 売上 | 23冊 × $12 ＝ $276 |
| 経費 | $118.52 |
| 純利益 | **$157.48**（7日間・1日あたり約$22） |

「楽な方法」という題名ですが、キャラ設計・投稿・商品づくりの作業はしっかり必要です。冒頭に出てくる高額な収入例は、この7日間の結果とは別の話です。

## このキットでやること

- キャラは **ミオ（美容）・ソウタ（宅トレ）・ユイ（家計）** の3人。ジャンルを分けて反応を比べます
- 勝ったキャラの商品をすぐ売れるように、**ワークブックは3冊とも完成済み** です
- 日本の法律とInstagramのルールに合わせて、AIであることを明示し、体験談や効果の断定は使いません

## 7日間の流れ

| 日 | やること |
|---|---|
| Day 1 | Higgsfieldでキャラの顔を固定し、Instagramで3アカウントを開設 |
| Day 2 | 素材をまとめて生成し、夜に自己紹介を投稿 |
| Day 3–4 | テスト投稿（3人とも同じ時刻に）、Day 4はストーリーズで投票 |
| Day 5 | 朝に数字で勝者を決め、ワークブックを出品して告知 |
| Day 6–7 | 中身紹介とよくある質問を投稿し、7日目の夜に集計 |

合計で13〜16時間ほどかかる見込みです。詳しくは [`03-7day-plan.md`](03-7day-plan.md) を見てください。

## 守ること

- [ ] プロフィールに「AIで生成したバーチャルキャラクター」と書いた
- [ ] 投稿のたびにInstagramのAIラベルをオンにした
- [ ] 体験談（使ってみた・やせた・貯まった）を書いていない。数字は計算例・モデルケースとして書いた
- [ ] 美容：化粧品の効能をこえる表現（シミが消える・ニキビが治るなど）をしていない（薬機法）
- [ ] 宅トレ：効果の断定や、けが・病気への助言をしていない
- [ ] 家計：特定の金融商品・保険をすすめていない
- [ ] 広告やアフィリエイトを載せるときは「PR」「広告」と書いた（ステマ規制）
- [ ] 実在の人物や既存のAIインフルエンサーに似ていないか確認した
- [ ] 出品前にワークブックを自分で通読した
- [ ] 特定商取引法に基づく表記と返品条件を、販売サービスのやり方に沿って表示した

**税金について**：会社員の場合、給与以外の所得が年20万円以下なら所得税の確定申告は不要ですが、住民税の申告は必要です。詳しくは税務署やお住まいの自治体に確認してください。

## ワークブックを作り直すとき

PDFとプレビュー画像は `workbooks/` のHTMLテンプレートから生成しています。文面を直したら、次のコマンドで作り直せます。

```bash
cd ai-influencer/workbooks
npm install
npm run build
```

中身は `workbooks/content/*.mjs` にあります。ページからはみ出す内容があると、ビルドがエラーで止まります。
