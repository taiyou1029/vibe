# 01. キャラクター設定書

ジャンルの違う3人を同時に走らせ、反応がいちばん良かった1人の商品を売ります（動画と同じ方式）。
ソウタだけ男性なので、テストでは「ジャンル × キャラ」の組み合わせごと比べることになります。

## 3人に共通するルール

| ルール | 理由 |
|---|---|
| プロフィールに「AIで生成したバーチャルキャラクター」と書く | 実在の人物だと誤認させないため。Instagramでも、本物に見えるAI生成コンテンツにはAIラベルが求められます |
| 投稿のたびにInstagramの「AIラベル」をオンにする | 同上（設定の場所はアプリのバージョンで変わることがあります） |
| 体験談を作らない | AIは使っても、やせても、貯めてもいません。「使ったら肌がきれいになった」「5kgやせた」「月3万円貯まった」を実体験として書くと、事実と違う表示になります。数字は「モデルケース」「計算例」として出します |
| 効果を断定しない | 美容は薬機法（化粧品の効能の範囲をこえる表現はNG）、運動は「◯日で−◯kg」のような断定がNG、家計は「絶対貯まる」がNG |
| 実在の人物・既存のAIインフルエンサーに似せない | 名前とハンドルは、公開前にInstagramとXで検索して重複を確認します |
| 広告やアフィリエイトを載せるときは「PR」「広告」と書く | 2023年10月からのステマ規制（景品表示法）の対象です。自分のワークブックを売るだけなら、自分の商品だと分かる書き方で十分です |

| ターゲット | 20〜30代の運動不足の会社員・在宅ワーカー（男女とも） |
| 発信の柱 | ①道具なし10分メニュー ②続けるコツ（最低ライン・きっかけづくり） ③休んだ日の立て直し方 |

| 表示名案 | ソウタ｜1日10分の宅トレ |
